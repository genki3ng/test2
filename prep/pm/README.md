## 典型 PM 面试轮次

多数公司 PM 面试由这几类轮次组合而成：

1. **Product Sense / Design（产品设计）**：开放设计题，如"改进 X""为某人群设计 Y"。考用户共情、结构化思维、方案取舍与产品判断。
2. **Analytical（指标与估算）**：定义成功指标、诊断"某指标掉了 5% 怎么查"、估算市场规模 / 用量、量化取舍。考数据敏感度与结构。
3. **Strategy / Execution（战略与执行）**：该不该进入新市场、竞品分析、GTM、排路线图优先级、跨职能推进落地。考商业判断与 owner 心态。
4. **Behavioral / Leadership（行为面）**：经历深挖、无正式授权下的影响力、冲突、向上沟通、失败复盘。考领导力与协作。

> 不同公司命名不同（有的把 estimation 并进 analytical，有的把 execution 单列），但**底层四类能力一致**。按面经反推每家的轮次结构 → [company-specific-prep.md](company-specific-prep.md)。

## 资深 PM（高级岗）侧重

- **产品设计**：不只给方案，要从**战略高度**框定问题、讲清为何这是值得做的问题、推动跨团队对齐。
- **指标与分析**：强调指标体系设计的判断力（北极星选择、护栏、Goodhart 风险）与对业务的影响，不只算对。
- **战略与执行**：把单点决策接回公司整体战略与资源分配；展现 0→1 与跨组织推进的领导力。
- **行为面**：重 **影响力 / 跨职能领导 / 在模糊中带方向**；初/中级更看 ownership 与执行扎实。

## 用 AI 备战面试：四步法

每道题都按这个闭环练，比刷题量更重要：

1. **抽题**：去 /practice 练习台从 [question-bank.md](question-bank.md) 抽一道（或让 Claude 按目标公司出题）。
2. **出声讲**：计时 3–5 分钟，像真面试一样**大声讲出来**（结构 > 完美措辞）。别在脑子里默想。
3. **看要点 + 自评**：对照该题「要点」找差距，点自评（😣/😐/😎），自动落 [practice-log.md](practice-log.md)。
4. **（可选）交批改**：把你的回答贴给 Claude，要它按"澄清 / 结构 / 取舍 / 业务连接 / 沟通"逐项点评 + 给改进版。

核心心法：**先把大方向做对**（核心用户、核心价值、北极星），别一上来抠功能细节；**会问澄清问题 > 知识本身**。

## 工作流

1. 选定目标公司 → 收集面经 → 反推该公司 PM 考点（偏产品设计还是战略？有无估算？技术深度？）→ 填进 [company-specific-prep.md](company-specific-prep.md)。
2. 把考点拆进 product-design / analytical-metrics / strategy-execution / behavioral 的 TODO。
3. 用四步法循环练，弱项（看 practice-log 自评）让 Claude 出补强材料。
4. 每场真面试后回填面经与反思到对应 [公司文件](../../pipeline/companies/)。
