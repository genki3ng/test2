# 战略与执行 / Strategy & Execution（速查 + study guide）

> 考商业判断 + owner 心态 + 跨职能推进。资深岗权重高：要把单点决策接回**公司整体战略**。
> 练法：从 [../question-bank.md](../question-bank.md) 抽 st 系列题。**先给结论，再用框架论证**，别把分析做成流水账。

## 一、该不该进入新市场 / 新业务

**框架：市场吸引力 × 制胜权利（right to win）→ 结论 → 进入方式**

- **市场吸引力**：规模（TAM/SAM/SOM）、增速、竞争格局、利润结构、监管。
- **制胜权利（right to win）**：我们有什么别人没有的 **unfair advantage**——现有用户、数据、渠道、品牌、技术、规模经济。两者都强才值得进。
- **明确结论**：进 / 不进 / 先试点，列关键假设和最大风险（讲判断，别骑墙）。
- **进入方式**：自建 vs 收购 vs 合作；MVP 试点先验证哪条假设。
- 资深加分：接回**公司整体战略与资源分配**——做这个要放弃什么。

## 二、竞品分析 / 应对强竞对

- 选**维度**对比（目标用户、核心价值、商业模式、增长引擎、护城河），别只列功能。
- 找我们的**差异化定位** + 对手的结构性弱点；判断哪些功能要跟、哪些不值得跟。
- **护城河四类**：网络效应、转换成本、规模经济、（专有）数据。我们能建哪种？
- 行动建议：**守住核心 + 在一个差异点做深**，而非全面对标被牵着走。

## 三、GTM（上市策略）/ 冷启动

**框架：目标 → 定位 → 渠道 → 定价 → 里程碑/指标**

- **目标**：抢份额？营收？教育市场？决定打法激进还是稳健。
- **定位**：一句话——"为谁、解决什么、凭什么比替代品好"。
- **渠道与获客**：哪些渠道触达目标人群；**CAC < LTV** 是否成立。
- **冷启动 / 双边市场**：先补哪一边（通常补稀缺侧/供给）、种子从哪来、补贴怎么退坡。
- **定价模型** + 里程碑 + 成功指标（激活/留存/口碑），以及失败如何快速止损。

## 四、路线图与优先级

**框架：先有目标(OKR) → 量化排序 → 平衡 → 对齐沟通**

- 优先级**服务于北极星与季度目标**，不是功能许愿单。
- **RICE 打分**：`(Reach × Impact × Confidence) ÷ Effort`。逐项讲清打分依据，别只给名字。
  - Reach：周期内影响多少用户/事件；Impact：对目标的影响强度；Confidence：证据充分度（%）；Effort：人月。
- 备选：**价值-成本矩阵**（高价值低成本先做）、Kano（基础/期望/兴奋型需求）。
- **平衡**：增长 vs 体验 vs 技术债 vs 平台投资；留 buffer 给突发与维护。
- **"不做什么"和"做什么"一样重要**——明确砍掉的，体现取舍。

## 五、跨职能推进（Execution）

> 偏执行/影响力，常与行为面交叉。详见 [../behavioral/README.md](../behavioral/README.md)。

- 先建**共识与北极星**，让 Eng/Design/数据/业务方看到对各自目标的价值。
- 厘清 **RACI**（谁负责/谁拍板/被咨询/被告知），画干系人地图，识别盟友与阻力。
- 把模糊目标**拆成里程碑 + owner + 节奏**（站会/周报），让进度可追踪。
- 主动暴露风险与依赖；阻塞时**升级有度**；用早期小胜建立信任。
- 应对变化：数据/市场变了，怎么重排优先级而不乱阵脚。

## 高频题型 → 起手式

| 题型 | 起手 |
|---|---|
| "要不要做 X 新业务" | 市场吸引力 × right to win → 明确结论 |
| "对手上线了我们的核心功能" | 守核心 + 一个差异点做深，判断要不要跟 |
| "给新产品定 GTM" | 目标 → 定位 → 渠道(CAC/LTV) → 冷启动 → 指标 |
| "排下季度路线图" | OKR → RICE 排序 → 平衡 → 明说不做什么 |
| "跨团队、你没管理权，怎么推" | 共识/北极星 → RACI → 里程碑+小胜 → 升级有度 |
