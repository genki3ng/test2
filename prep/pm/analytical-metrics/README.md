# 指标与分析 / Analytical（速查 + study guide）

> 考数据敏感度 + 结构化排查 + 量化判断。三大题型：**定义指标**、**诊断下跌**、**估算**（+ 量化取舍）。
> 练法：从 [../question-bank.md](../question-bank.md) 抽 me 系列题。**结构 > 精确**——讲清思路框架比算出漂亮数字更重要。

## 一、定义成功指标

**框架：澄清 → 目标 → 分层 → 取舍**

- **澄清**：功能是什么、目标用户、生命周期阶段、背后业务目标。
- **指标分层**：
  - **北极星（1 个）**：代表长期用户价值，全公司/全组对齐的那个数。
  - **输入 / 驱动指标**：能撬动北极星的可操作前置量（如激活率、首日留存）。
  - **护栏指标（guardrail）**：防止为了主指标伤害大盘（留存、申诉率、时延、用户健康）。
- **北极星三原则**：①与长期价值一致 ②能被该产品影响 ③不易被刷（不是虚荣指标）。
- **指标族速记**：采用(adoption) → 参与(engagement) → 留存(retention) → 变现(monetization)。按功能目标选主指标。
- **收尾**：指标冲突如何权衡 + 下一步常接 A/B 验因果。

> ⚠️ **Goodhart 定律**：指标一旦成为目标就会被钻空子（刷量、标题党）。选指标时主动说怎么防。

## 二、诊断指标下跌（"X 掉了 5% 怎么查"）

**框架：止血澄清 → 排数据问题 → 分群 → 漏斗 → 内外因 → 根因+验证**

1. **澄清 + 量级**：跌了多少、何时起、突变还是渐变、影响范围（全量 vs 局部）。
2. **先排数据问题**（最容易被忽略也最常见）：埋点/日志故障、口径变更、节假日季节性、重复/缺失。
3. **分群定位**：按 **维度切**——地区 / 平台(iOS/安卓/web) / 新老用户 / app 版本 / 获客渠道——看是普跌还是某群塌。
4. **漏斗拆解**：曝光 → 点击 → 转化 → 完成，定位掉在哪一环。
5. **内因 vs 外因**：内（发版/改版/价格/策略变更）vs 外（竞品/政策/大盘/舆情）。对齐发布时间线。
6. **收敛**：给根因假设（按可能性排序）+ 每个怎么验证 + 短期缓解 vs 长期修复。

> 说出"我会**先看哪张图 / 哪个分群**"，比穷举所有可能更显结构。

## 三、估算题（guesstimate）

**框架：选路径 → 列假设 → 分段估 → sanity check → 接回业务**

- **两条路径**：
  - 自上而下：总体 × 渗透率 × 频次（如 人口 × 用某 app 比例 × 日均次数）。
  - 自下而上：单元 × 数量（如 单店日销 × 门店数）。
- **列假设并标量级**：人口、渗透率、频次、客单价——数字取整好算，显式说出来。
- **分段估**：分人群 / 时段 / 场景，避免一个系数拍死全场。
- **sanity check**：量级对不对？能否换条路径交叉验证？哪个假设最敏感？
- **接回业务**："若用于估市场规模 / 定容量，我会再校准最敏感的 X。"

## 四、量化取舍（trade-off）

- 把两边都**指标化**：收益侧（增量收入/参与）vs 代价侧（留存、满意度、长期 LTV）。
- **对齐口径**：短期 vs 长期要么折现到同一时点，要么明说时间窗。
- **设护栏阈值**：护栏指标跌破某线就不上；用 A/B 量化净效应。
- 给建议时讲清你**最看重的长期指标**，不被短期数字绑架。

## 量化"难量化的东西"

- 把抽象拆成可观测**代理指标**（proxy），每个说清为何相关。
- 组合多信号成指数，抗刷（"内容质量" = 完播 + 复访 + 举报率 + 人工抽检）。
- 谈 proxy 的失真与校正（Goodhart）。

## 速记卡

- 留存看法：N-day 留存、滚动留存、留存曲线是否变平（flatten = 有 PMF 信号）。
- 比率指标变动 = 分子变 or 分母变 or 结构变（辛普森！）——先拆分子分母。
- AARRR 海盗指标：Acquisition / Activation / Retention / Revenue / Referral，定指标体系时扫一遍。
