# 练手前冲刺计划（2–3 周）— Product Manager

> 模板占位 —— 把目标公司、起止日期、每周重点改成你自己的。
> 起止：**2026-01-15 → 2026-02-04**（示例，按你的节奏改）。计划是活的，跟不上就砍量保重点。

## 策略权重（别平均用力）
- ✅ **产品设计 / Product Sense**：最高频，用 CIRCLES + 大量 reps 把"讲清楚"练成肌肉记忆。
- 🎯 **指标与分析**：定义指标 + 诊断下跌 + 估算，结构化优先于精确，多数人弱项。
- 🔁 **战略与执行**：用真实公司/业务套 GTM、竞品、RICE 框架，体现高度（尤其高级岗）。
- 📣 **行为面**：先把 3–4 个招牌 STAR 故事写定稿、练顺，再谈细节。

## 并行轨：内推 outreach 现在就开
- [ ] 给每个目标公司各找 1 个内推渠道 → 见 [pipeline/referrals.md](../../pipeline/referrals.md)。
- [ ] 投递后 recruiter screen 一般 1–2 周才来，**不用等冲刺结束再投**。
- [ ] 整理 1 份 PM 简历要点 + 招牌项目一句话，内推时随手发得出。

---

## Week 1（1/15–1/21）：搭框架 + 起跑内推
- [ ] 吃透 **CIRCLES** + 改进题 / 设计题答题骨架，练 3 道产品设计题（出声讲）。
- [ ] 过一遍指标分层（北极星 + 输入 + 护栏），练 2 道"定义成功指标"。
- [ ] 练 2 道估算题，重点练"说思路结构"而非算得快。
- [ ] 给每个目标公司各找 1 个内推渠道并发出第一波。
- [ ] 写 1 个招牌 STAR 故事初稿（最有影响力的项目）。

## Week 2（1/22–1/28）：深度（诊断 + 战略 + 取舍）
- [ ] 练"指标掉了 X% 怎么查"诊断框架 + 2 题（漏斗 + 分群）。
- [ ] 战略题各备 1 个口述：进入新市场（吸引力 × right to win）、竞品分析、GTM/冷启动。
- [ ] 路线图与优先级：用 **RICE** / 价值-成本矩阵给一个真实场景排序。
- [ ] 量化 trade-off 练 1 题（如广告 vs 体验）。
- [ ] 再写 2 个 STAR 故事（无授权影响力 + 冲突），覆盖核心信号。

## Week 3（1/29–2/4）：实战化 + 公司定制 + 收口
- [ ] 真人 mock ≥2 场（1 产品设计 + 1 指标或战略），录下来复盘，用 [mock-interview-bank.md](mock-interview-bank.md) 自评表打分。
- [ ] 公司定制：目标公司各"可能问什么 + 我的角度"过一遍 → [company-specific-prep.md](company-specific-prep.md)。
- [ ] 行为面把 STAR + TMAY 串顺，准备好"重来会怎么改"反思。
- [ ] 查漏：估算 sanity check、诊断别漏数据问题、设计题别忘成功指标与护栏。

---

## 出关标准（达到即可开冲）
- [ ] 能对任意产品 5 分钟内给出"目标→用户/痛点→方案取舍→成功指标+护栏"且不慌。
- [ ] 能现场把"某指标掉了 5%"结构化拆到根因假设 + 验证方式。
- [ ] 估算题能讲清思路结构、列假设、做 sanity check。
- [ ] 3–4 个 STAR 故事讲顺、能量化结果、有反思，且覆盖影响力/冲突/向上沟通。
- [ ] ≥2 场 mock 复盘完、坑已记。
