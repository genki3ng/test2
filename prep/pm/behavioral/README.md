# 行为面 / Leadership（速查 + study guide）

> 考领导力、协作、影响力与成长心态。PM 行为面尤其重 **无正式授权下推动事情**。
> 练法：从 [../question-bank.md](../question-bank.md) 抽 bh 系列题。**先写定稿 3–4 个招牌故事**，再练顺，别每次现编。

## 核心框架：STAR

| 字母 | 含义 | 占比 | 注意 |
|---|---|---|---|
| **S**ituation | 背景 | 短 | 一两句交代清楚，别铺垫太久 |
| **T**ask | 你的目标/职责 | 短 | 讲清**你**的角色，不是团队泛泛 |
| **A**ction | 你具体做了什么 | **最长** | 重头戏：突出"我"的决策与行动，分 2–3 步讲 |
| **R**esult | 结果 | 中 | **量化**（指标↑X%、影响 N 用户/营收）+ 学到什么 |

> 反模式：S 讲一半时间、A 用"我们"模糊带过、R 没数字。**面试官要听的是 YOU 做了什么。**

## 招牌故事矩阵（先备这几个）

每个故事尽量能套多个问题。建议至少备：

| 故事 | 主打信号 | 可复用到的问题 |
|---|---|---|
| **最有影响力的项目** | 产品判断 + 量化结果 | TMAY、proudest、影响力、driving project |
| **无授权推动跨团队** | 影响力 / 领导力 | 跨职能、说服、推动落地 |
| **一次冲突 / 严重分歧** | 成熟度 / 对事不对人 | 与 Eng/Design/老板冲突、难合作的人 |
| **一次失败 / 错误决策** | 成长心态 / owner | failure、mistake、重来怎么改 |

## 高频题 → 怎么答

### 影响力（无正式授权推动）—— PM 必杀题
- 场景里你**没有命令权**（跨团队、对上、对外部）。
- Action：倾听对方诉求 → 找共同目标 → 用**数据 + 用户故事**说服 → 必要时妥协 / 做实验让数据说话。
- Result：达成的共识与产出，体现"靠影响力而非职权"。

### 冲突 / 意见不合
- 讲清是**观点/优先级**冲突，不是人身。
- 先理解对方立场与约束 → 用证据对齐目标 → 能为大局让步也能据理力争。
- 结尾：关系维护好了 + 决策更优了 + 学到什么。

### 向上沟通 / 说服领导
- 你看到领导可能没看到的信号（数据/用户/市场）。
- 准备证据、选时机、用对方关心的目标和语言、给**可选项**而非只抱怨。
- 处理"领导不同意"：何时 **disagree and commit**、何时继续争取，讲清判断。

### 失败 / 复盘
- 选**真失败**，诚实讲你的责任份额（不甩锅）。
- 重点在**反思与改变**：学到什么、之后怎么做不一样、有没有验证改进有效。
- 结尾积极，转成可迁移方法论。

## 通用 tips

- **结果先行**也可以：有时先抛结果勾住注意力，再倒叙过程。
- **量化**一切能量化的：%、规模、时间、营收、留存。
- 每个故事备一个 **"如果重来"** 的反思，几乎必被追问。
- 准备 **TMAY**（Tell me about yourself）：30–60 秒，把经历串成"为什么我适合这个岗位"的主线。
- 反问环节也是评分项：问该组真实挑战、成功标准、团队怎么决策。
