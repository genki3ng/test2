# 各公司定制题：面试重点 + 我的角度（pipeline 全覆盖）— Data Engineer

> 每家目标公司开一段，用 Claude 生成「业务/数据栈 → 面试重点 → 可能问 + 我的角度 → 注意」。
> 用法：投/面某家前过一遍对应段；面后把真实题回填对应 [pipeline/companies/*.md](../../pipeline/companies/)。
> 下面三家是**示例占位**（虚构公司），请替换成你自己的目标公司。

## 先搞清楚每家的四件事（DE 通用画像）

1. **数据栈**：仓是 Snowflake / BigQuery / Redshift / Databricks？计算是 Spark / Flink？调度是 Airflow / Dagster / 自研？流是 Kafka？——决定 SQL 方言、Spark 深度、设计题侧重。
2. **数据形态**：偏批还是偏流？数据规模（TB/PB）？是否有强实时诉求？——决定考批 vs 流、倾斜、状态管理。
3. **团队定位**：平台型 DE（建工具/框架）还是分析型 DE（建数仓/宽表服务下游）？——决定考系统设计还是建模。
4. **难度信号**：从面经判断 SQL 难度、是否手撕 Spark、设计题权重、有没有 take-home。

## Northwind（示例：电商 / 双边市场）

- **业务/数据栈**：占位——用 Claude 补（典型如订单/履约事件流、批+流混合、列存数仓）。
- **面试重点**：占位——多半重 SQL（GMV/留存/漏斗）+ 维度建模（订单事实表、商品/用户/门店维度、SCD）。
- **可能问 + 我的角度**：占位——如"设计订单分析数仓""退款率怎么算/怎么建模"。
- **注意**：占位——口径（GMV 含不含退款/税费）一定先澄清。

## Vertex Cloud（示例：B2B SaaS / 基础设施）

- **业务/数据栈**：占位——用 Claude 补（典型如用量计费事件、近实时 CDC、lakehouse）。
- **面试重点**：占位——多半重管道/系统设计（CDC、幂等、数据质量、SLA）+ Spark。
- **可能问 + 我的角度**：占位——如"把业务库同步到数仓""用量计费管道怎么保证不重不漏"。
- **注意**：占位——强调幂等/exactly-once 语义与对账。

## Helios Media（示例：内容 / 广告平台）

- **业务/数据栈**：占位——用 Claude 补（典型如海量曝光/点击事件流、流处理、实时大盘）。
- **面试重点**：占位——多半重流处理（窗口、watermark、倾斜）+ 大规模聚合。
- **可能问 + 我的角度**：占位——如"实时 CTR 大盘""热点内容导致的数据倾斜怎么解"。
- **注意**：占位——事件时间 vs 处理时间、迟到数据处理要讲清。
