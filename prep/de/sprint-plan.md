# 练手前冲刺计划（2–3 周）— Data Engineer

> 模板占位 —— 把目标公司、起止日期、每周重点改成你自己的。
> 起止：**2026-01-15 → 2026-02-04**（示例，按你的节奏改）。计划是活的，跟不上就砍量保重点。

## 策略权重（别平均用力）

- ✅ **SQL & 建模**：DE 几乎必考、最稳的拿分项——窗口/留存/漏斗写到肌肉记忆，建模能口述星型/SCD。
- 🎯 **管道 / 系统设计**：高级岗的分水岭，多数人弱项——用框架 + reps 补（批/流、幂等、回填、数据质量、调度）。
- 🎯 **Coding（Python/Spark）**：流式处理 + Spark 倾斜/shuffle/broadcast 这几个高频点讲透。
- 🔁 **行为面保温**：每周磨 1–2 个 STAR，别临场抓瞎。

## Week 1（1/15–1/21）：SQL & 建模打底 + 起跑内推
- [ ] 练 6–8 道 SQL：窗口函数（累计/环比/排名）、去重三写法、留存 + 漏斗各一道。
- [ ] 维度建模口述：星型 vs 雪花、事实/维度表、SCD Type 1/2/3 各能 2 分钟讲清。
- [ ] 范式 vs 反范式、增量 vs 全量 各备一个口述 + 适用场景。
- [ ] 给每个目标公司各找 1 个内推渠道、发出第一波 outreach。

## Week 2（1/22–1/28）：Coding(Spark) + 管道设计
- [ ] Spark 核心：shuffle / 宽窄依赖 / 倾斜 skew / broadcast join / 分区并行度，能现场讲优化。
- [ ] Python 数据处理：流式 Top-K、分块去重，讲清复杂度与内存约束。
- [ ] 管道设计框架：批 vs 流、幂等、回填、数据质量 + SLA、调度 DAG——各过一遍。
- [ ] CDC / lakehouse / 文件格式（Parquet 列存）各能说清"是什么 + 何时用"。

## Week 3（1/29–2/4）：实战化 + 公司定制 + 收口
- [ ] 真人 mock ≥2 场（1 SQL+建模 / 1 管道设计），录下来复盘。
- [ ] 公司定制：目标公司各"技术栈 + 可能问 + 我的角度"过一遍 → [company-specific-prep.md](company-specific-prep.md)。
- [ ] 行为面定稿 STAR：管道改进 / 数据事故复盘 / 跨团队 各一个 + TMAY。
- [ ] 查漏：幂等/回填/数据质量/倾斜这几个高频追问点的二次深挖。

## 出关标准（达到即可开冲）
- [ ] 任意给一张表能 5 分钟内写出窗口/留存/漏斗查询并讲清口径与边界。
- [ ] 能现场设计一条端到端管道（含批/流取舍、幂等、回填、数据质量、调度），并讲清 trade-off。
- [ ] Spark 倾斜/shuffle/broadcast 能各 2 分钟讲清"怎么定位 + 怎么解决"。
- [ ] ≥2 场 mock 复盘完、坑已记；3 个 STAR 故事能脱稿讲。
