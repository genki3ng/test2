# 练手前冲刺计划（2–3 周）

> 模板占位——把目标公司、起止日期、每周重点改成你自己的（见 GETTING-STARTED.md）。
> 起止：**2026-01-15 → 2026-02-04**（示例，按你的节奏改）。计划是活的，跟不上就砍量保重点。

## 策略权重（别平均用力）

- ✅ **统计/实验**：擦亮你的强项，重点练"讲清楚"。
- 🎯 **产品 Sense**：用框架 + 大量 reps 补，多数人弱项。
- 🔁 **SQL/Python 保温**：每周少量，别荒废。

## 并行轨：内推 outreach **现在就开**（有 1–2 周时滞）

- [ ] 给目标公司各找 1 个内推 → 见 [pipeline/referrals.md](../pipeline/referrals.md)。
- [ ] 投递后 recruiter screen 一般 1–2 周后才来，**不用等冲刺结束再投**。

---

## Week 1（1/15–1/21）：擦亮根基 + 起跑内推

- [ ] 练 5 道 SQL 题（window / 聚合 / 留存）。
- [ ] 过一遍实验设计框架（样本量 / 护栏 / 坑）。
- [ ] 练 3 题"定义指标"，先自己讲再对照框架。
- [ ] 给目标公司各找 1 个内推渠道。

## Week 2（1/22–1/28）：深度（因果 + 诊断）

- [ ] 因果方法各备 1 个"怎么用 + 适用/陷阱"口述。
- [ ] 练 ratio metric 诊断框架 + 2 题。
- [ ] 过一遍 marketplace / 订阅等业务指标体系。
- [ ] SQL 保温 1–2 题。

## Week 3（1/29–2/4）：实战化 + 公司定制 + 收口

- [ ] 真人 mock ≥2 场（1 实验 + 1 产品 sense），录下来复盘。
- [ ] 公司定制：目标公司各"可能问 + 我的角度"过一遍。
- [ ] 行为面过 STAR + TMAY。
- [ ] A/B 坑点查漏（SRM / peeking / novelty / 干扰 / 多重比较）。

---

## 出关标准（达到即可开冲）

- [ ] 能对任意产品 5 分钟内给出"目标→北极星+护栏→诊断维度→取舍建议"且不慌。
- [ ] 能现场设计一个干净 A/B（含护栏、MDE、坑）并讲清何时不该做。
- [ ] 因果方法各能 2 分钟讲清"怎么用+陷阱"。
- [ ] ≥2 场 mock 复盘完、坑已记。
