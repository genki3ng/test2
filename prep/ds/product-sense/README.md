> 没有标准答案，考的是**结构化思维 + 业务嗅觉 + 取舍**。

## 通用答题框架

1. **澄清**：产品/功能是什么、目标用户、所处生命周期、业务目标。
2. **定目标**：这个产品/功能想达成什么（增长？留存？变现？参与度？）。
3. **定指标**：北极星指标 + 输入指标 + 护栏指标；为什么选它、怎么算。
4. **拆解 / 诊断**：按维度（用户群/地区/平台/时间/漏斗环节）拆，提假设逐一排查。
5. **取舍 & 建议**：指标冲突时怎么权衡，给出可执行建议与下一步验证（常接 A/B 实验）。

## 高频题型清单

- [ ] **定义成功指标**：为某产品/功能设计衡量体系（如短视频、marketplace、通知）
- [ ] **诊断指标变化**："X 指标上周掉了 5%，怎么查？"——结构化排查（真实下降 vs 数据问题 vs 季节性 vs 外部）
- [ ] **目标设定 / 北极星**：为新产品定北极星指标并论证
- [ ] **权衡 trade-off**：参与度 vs 用户健康、短期收入 vs 长期留存
- [ ] **该不该做/上线某功能**：用数据论证决策
- [ ] **衡量难量化的东西**：如"内容质量""用户信任"
