# Coding（DS&A）— 算法与数据结构 cheatsheet

> 目标：中等难度题 25–35 分钟内**边讲边写**出 bug-free 解，并报复杂度。SWE 面试最核心、最可量化提升的板块。
> 用法：按下方题型清单识别「这题属于哪个模式」→ 套模板 → 写 → 报复杂度 → 跑例子 → 列 edge。配合 [../question-bank.md](../question-bank.md) 的 `ds-*` 抽题练。

## 解题通用流程（每道题都走一遍）

1. **复述 + 澄清**：输入/输出/约束/边界（空？负数？重复？范围多大？已排序？），举个小例子确认理解。
2. **先想暴力解 + 复杂度**：哪怕 O(n²) 也先说，建立基线，再想优化方向。
3. **找模式 + 优化**：能不能用哈希降查找、双指针/滑窗减一层循环、排序换单调性、二分降到 log、DP 去重叠子问题。
4. **讲清思路再写**：先口述算法 + 目标复杂度，得到面试官点头再动手。
5. **写**：结构清晰、命名清楚、边写边讲。
6. **验证**：跑 1 个正常例子 + 主动列 edge case，能跑就跑。
7. **报复杂度 + 谈优化**：时间/空间，再聊「如果输入变大 / 要更省空间怎么办」。

## 题型 → 模式速查（识别是第一步）

| 信号 / 题面特征 | 大概率模式 | 典型套路 |
|---|---|---|
| 查找/去重/计数/配对 | **哈希表** | 边遍历边查补值，O(n²)→O(n) |
| 有序数组找一对/区间 | **双指针（对撞）** | 左右往中间收 |
| 原地删/去重、链表中点/判环 | **双指针（快慢）** | 读写指针 / Floyd |
| 连续子数组/子串求最长最短 | **滑动窗口** | 右扩左缩，维护窗口状态 |
| 有序 / 求「最小满足值」 | **二分查找** | 值或下标上二分 + 单调 check |
| 最短路（无权）/层序 | **BFS** | 队列，按层 |
| 穷举路径/连通性/所有方案 | **DFS / 回溯** | 选择→递归→撤销 |
| 求最值/方案数且有阶段选择 | **动态规划** | 状态+转移+base+顺序 |
| Top-K / 第 K 大 / 数据流 | **堆** | 大小为 K 的堆 / 双堆 |
| 依赖关系/连通/最短路 | **图** | 拓扑 / 并查集 / Dijkstra |

## 模板（背到肌肉记忆）

**滑动窗口（变长，求最长合法）**
```
l = 0; 维护窗口状态
for r in range(n):
    纳入 nums[r]
    while 窗口非法:
        移出 nums[l]; l += 1
    更新答案 = max(答案, r - l + 1)
```

**二分（找左边界，区间 [l,r)）**
```
l, r = 0, n
while l < r:
    mid = l + (r - l) // 2
    if check(mid): r = mid      # 满足，继续往左找
    else: l = mid + 1
return l
```

**BFS（矩阵/图，求层数/最短）**
```
queue = [起点]; visited.add(起点)
while queue:
    for _ in range(len(queue)):   # 按层
        cur = queue.popleft()
        for nxt in neighbors(cur):
            if nxt not in visited:
                visited.add(nxt); queue.append(nxt)
    depth += 1
```

**回溯（子集/排列/组合）**
```
def backtrack(start, path):
    收集 path（按题意）
    for i in range(start, n):
        if 需要去重 and 重复: continue
        path.append(选择)
        backtrack(i 或 i+1, path)
        path.pop()              # 撤销
```

**DP（先记忆化想清楚，再翻迭代）**
```
定义 dp[i] 的含义（一句话写下来）
写转移方程 dp[i] = f(dp[更小的])
定 base case
定遍历顺序（保证依赖先算）
能滚动就降空间
```

## 复杂度速记

- 常见量级：O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ) < O(n!)。
- 排序 O(n log n)；哈希查找 O(1) 摊还；堆 push/pop O(log n)；二分 O(log n)；图遍历 O(V+E)。
- 递归别忘**栈空间** = 递归深度；摊还分析（动态数组扩容、并查集路径压缩）。
- 报复杂度时讲「为什么」：每个元素进出窗口各一次 → O(n)。

## edge case 习惯清单（养成肌肉记忆）

- 空输入 / 单元素 / 两元素
- 最大最小值、整数溢出（`mid` 用 `l+(r-l)/2`）
- 重复元素、负数、零
- 已排序 / 逆序 / 全相同
- 链表：空表、单节点、环；树：空树、单边退化、单节点
- 越界 / 下标 ±1（off-by-one 是最常见 bug）
