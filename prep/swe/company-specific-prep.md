# 各公司定制：面试形式 + 考点 + 我的角度 — Software Engineer

> 模板占位 —— 每家目标公司开一段，用 Claude 生成「面试形式 → 考点重点 → 可能问 + 我的角度 → 注意」。
> SWE 公司差异大，**先问清这几样**再定制（去面经/recruiter 确认）：
> - **轮次构成**：几轮 coding？有无 System Design / OOD？有无领域专项轮？
> - **语言/环境**：可用任意语言还是限定？白板 vs 共享编辑器 vs 可运行 IDE？能否查文档？
> - **难度与风格**：coding 偏中等还是偏难？重算法还是重工程实现？System Design 深度？
> - **价值观/行为面**：有没有专门的 behavioral/leadership 轮、对应什么价值观关键词。
> 用法：投/面某家前过一遍对应段；面后把真实题回填对应 [pipeline/companies/*.md](../../pipeline/companies/)。

- **面试形式**：模板占位——填几轮 coding + 是否有 system design / OOD。
- **考点重点**：模板占位——如分布式系统设计深、coding 中等偏算法。
- **可能问 + 我的角度**：模板占位——用 Claude 结合其业务出 2–3 道可能题 + 你的答法。
- **注意**：模板占位——语言/环境/价值观关键词。
