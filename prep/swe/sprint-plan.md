# 练手前冲刺计划（2–3 周）— Software Engineer

> 模板占位 —— 把目标公司、起止日期、每周重点改成你自己的。
> 起止：**2026-01-15 → 2026-02-04**（示例，按你的节奏改）。计划是活的，跟不上就砍量保重点。

## 策略权重（别平均用力）

- ✅ **Coding（DS&A）**：占大多数轮次、最可量化提升——**每天**保持手感，按薄弱题型刷。
- 🎯 **System Design**：资深岗权重高、多数人弱项——用框架 + 经典题 reps 补，重「讲清取舍」。
- 🧩 **OOD/LLD**：中高级常考一轮——背模板 + 2–3 道经典题（停车场/电梯）讲熟。
- 💬 **Behavioral**：定稿 2–3 个强 STAR 故事，别裸考。

## 并行轨：内推 outreach 现在就开

- [ ] 给目标公司各找 1 个内推渠道（投递后 recruiter screen 常 1–2 周才来，别等冲刺结束再投）。
- [ ] 确认每家面试形式：几轮 coding / 有无 system design / OOD / 语言要求。
- [ ] 准备一份脱敏简历亮点清单，喂给行为面故事。

---

## Week 1（1/15–1/21）：Coding 根基 + 起跑内推
- [ ] 每天 2–3 题：数组/字符串、哈希表、双指针、滑动窗口（先按模板讲思路再写）。
- [ ] 二分查找 + 三类变体（找边界 / 旋转数组 / 二分答案）各 1 题。
- [ ] BFS/DFS 模板各 1 题（矩阵连通分量 + 层序）。
- [ ] 给目标公司各找 1 个内推渠道，确认面试形式。
- [ ] 养成收尾习惯：报复杂度 + 跑一个例子 + 主动列 edge case。

## Week 2（1/22–1/28）：DP/图 + System Design 起步
- [ ] DP：识别信号 + 状态设计；背包 / LIS / 编辑距离各 1 题。
- [ ] 图：拓扑排序、并查集、Dijkstra 各 1 题。
- [ ] 堆 / Top-K / 数据流中位数 1–2 题。
- [ ] System Design：过一遍 7 步框架，做短链 + Feed 流 2 道，出声讲全程。
- [ ] OOD：背回溯式「选择→递归→撤销」与 SOLID，先讲停车场。

## Week 3（1/29–2/4）：实战化 + 设计深化 + 收口
- [ ] 真人/录音 mock ≥3 场（2 coding + 1 design），录下来复盘。
- [ ] System Design 再做聊天系统 + 限流器，深挖一个组件（缓存/分片/一致性）。
- [ ] OOD 电梯 + 图书馆讲熟，能聊并发与设计模式。
- [ ] Behavioral：STAR 故事 2–3 个定稿 + TMAY 计时过。
- [ ] Coding 查漏：把 practice-log 里 😣/😐 的题型重刷。

---

## 出关标准（达到即可开冲）
- [ ] 中等 coding 题能在 25–35 分钟内边讲边写出 bug-free 解，并报复杂度。
- [ ] 任意 System Design 能 5 分钟内拉出「澄清→估算→API→数据模型→组件→扩展+取舍」骨架。
- [ ] 一道 OOD（停车场/电梯）能讲清类设计 + 1 个设计模式 + 扩展性。
- [ ] 2–3 个 STAR 故事讲熟、TMAY 60–90 秒不慌。
- [ ] ≥3 场 mock 复盘完、坑已记进 practice-log。
