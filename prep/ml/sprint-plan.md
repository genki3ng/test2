# 练手前冲刺计划（2–3 周）— Machine Learning Engineer

> 模板占位 —— 把目标公司、起止日期、每周重点改成你自己的。
> 起止：**2026-01-15 → 2026-02-04**（示例，按你的节奏改）。计划是活的，跟不上就砍量保重点。

## 策略权重（别平均用力）
- ✅ **ML 基础（建模/评估）**：擦亮强项，重点练「把直觉讲成原理」——指标取舍、过拟合、偏差方差。
- 🎯 **ML 系统设计**：多数人的胜负手，用框架 + 大量 reps 补（召回+精排、特征平台、训练-服务一致）。
- 🔁 **Coding（DS&A）保温**：与 SWE 同源但通常稍浅，每周少量保手感，别荒废。
- 🗣 **行为面**：定稿 5–6 个 STAR 故事（含一次模型上线事故复盘），平时积累。

## 并行轨：内推 outreach 现在就开
- [ ] 给每家目标公司各找 1 个内推渠道 → 见 [pipeline/referrals.md](../../pipeline/referrals.md)。
- [ ] 投递后 recruiter screen 一般 1–2 周才来，**不用等冲刺结束再投**。
- [ ] 抓目标组的 JD / 面经，反推该组偏推荐/NLP/CV/排序，定制系统设计准备。

---

## Week 1（1/15–1/21）：擦亮根基 + 起跑内推
- [ ] ML 基础过一遍：偏差方差、过拟合/正则、分类与回归评估指标，每个能 2 分钟口述。
- [ ] Coding 保温：刷 5 题（哈希/双指针/BFS-DFS 各覆盖），出声讲思路与复杂度。
- [ ] 系统设计入门：把「召回 + 精排两阶段」骨架背熟，画一遍架构图。
- [ ] 给每家目标公司各找 1 个内推渠道，发出第一批 outreach。

## Week 2（1/22–1/28）：系统设计深度 + 建模细节
- [ ] 系统设计练 3 题（推荐/排序、特征平台、训练-服务 skew），先自己讲再对照要点。
- [ ] 深挖：类别不平衡、树模型 vs 神经网络、embedding、损失函数选择。
- [ ] Coding：DP + 堆/Top-K 各 3 题，重点把状态定义与复杂度讲清。
- [ ] 行为面：写定 3 个 STAR 故事，含一次模型上线事故复盘。

## Week 3（1/29–2/4）：实战化 + 公司定制 + 收口
- [ ] 真人 mock ≥2 场（1 ML 系统设计 + 1 coding 或 ML 深广度），录下来复盘。
- [ ] 公司定制：每家目标公司的业务域 → 可能的系统设计题 + 我的角度，各过一遍。
- [ ] 在线/离线评估 + A/B + 上线监控/回滚串成一条线，能完整讲。
- [ ] 行为面查漏：STAR + TMAY 全过一遍，定稿剩余故事。

---

## 出关标准（达到即可开冲）
- [ ] 能在 35 分钟内设计一个推荐/排序系统（澄清→召回+精排→特征→评估→上线监控）且不慌。
- [ ] 任意一个 ML 基础概念能 2 分钟讲清「是什么 + 怎么用 + 坑」。
- [ ] Coding 中频题能边写边讲、报准时间/空间复杂度。
- [ ] ≥2 场 mock 复盘完、坑已记；5–6 个 STAR 故事定稿。
