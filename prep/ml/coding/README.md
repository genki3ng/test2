# Coding（DS&A）— MLE 精简版

> 目标：中频算法题**边写边讲、报准复杂度、覆盖 edge case**。MLE 的 coding 与 SWE 同源，但通常深度略浅、更看重沟通与代码清晰。题库见 [../question-bank.md](../question-bank.md) 的「算法与数据结构」。

## 计划

- 节奏：<每天/每周 N 题，按时间调整>，重质不重量——每题出声讲一遍。
- 平台：LeetCode（按 tag 刷高频中等题）、NeetCode 150 精简清单。
- 别钻竞赛难题；MLE 重「中频题写得快、说得清」。

## 必练题型（勾掉 = 已熟练）

- [ ] **数组 / 哈希**：两数之和、和为 k 子数组、出现频率（哈希降复杂度）
- [ ] **双指针 / 滑动窗口**：有序两数和、三数和、最长无重复子串、最小覆盖子串
- [ ] **栈 / 队列**：有效括号、单调栈（下一个更大元素）、用栈实现队列
- [ ] **二分查找**：有序数组查找、旋转数组、查找边界、二分答案
- [ ] **链表**：反转、判环、找中点、合并有序链表
- [ ] **BFS / DFS**：岛屿数量、矩阵最短路、克隆图、拓扑排序
- [ ] **DP**：爬楼梯、打家劫舍、LCS、0/1 背包、编辑距离
- [ ] **堆 / Top-K**：前 K 大、合并 K 个链表、数据流中位数
- [ ] **回溯**：子集、排列、组合、N 皇后（按需）

## 核心套路速查（cheatsheet）

| 信号 / 题面 | 想到的工具 | 复杂度 |
|---|---|---|
| 「找一对 / 是否存在某值」 | 哈希表（边遍历边查补值） | O(n)/O(n) |
| 有序数组 / 求一对和 / 盛水 | 对撞双指针 | O(n)/O(1) |
| 「最长 / 最短满足条件的连续子串」 | 滑动窗口 | O(n) |
| 「下一个更大 / 更小」 | 单调栈 | O(n) |
| 有序 / 半有序里查找 / 求最值阈值 | 二分查找 / 二分答案 | O(log n) |
| 无权图最短路 / 层序 | BFS + 队列 | O(V+E) |
| 连通块 / 全路径 / 拓扑 | DFS / 回溯 / 拓扑 | O(V+E) |
| 「最优子结构 + 重叠子问题」 | 动态规划 | 看状态数 × 转移 |
| 「前 K / 第 K / 流式最值」 | 堆（大小 K）/ Quickselect | O(n log k) / 平均 O(n) |

## 复杂度备忘

- 报复杂度：先看主循环嵌套与每步代价；递归用递归树/主定理。
- 哈希：平均 O(1)、最坏 O(n)（碰撞）；排序 O(n log n) 是常见基线。
- 空间别漏**递归栈**（DFS 最坏 O(n)）和返回结果占用。
- 摊还：动态数组 push 均摊 O(1)；单调栈每元素进出各一次 → 整体 O(n)。

## 答题流程（面试现场）

1. **复述 + 澄清**：确认输入范围、是否有序、是否有重复/负数、要返回什么。
2. **先报暴力**：给出朴素解 + 复杂度，再说怎么优化（换数据结构 / 双指针 / DP）。
3. **讲思路再写**：边写边解释关键步骤；变量命名清晰。
4. **跑用例 + 边界**：空输入、单元素、重复、最大规模；自测一遍。
5. **报最终复杂度**：时间 + 空间，并说还能否更优。
