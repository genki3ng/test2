# Mock 面试题库 + 自评表 — Machine Learning Engineer

> 用 Claude 当面试官跑 mock，或找朋友互面。题号可引用 [question-bank.md](question-bank.md)。
> 目标：在「像真的」的压力下把结构、取舍、复杂度讲顺，并暴露薄弱点。

## 如何跑一场 ~60 分钟 MLE mock

- **10 分钟 Coding**：抽一道中频算法题，限时写 + 出声讲 + 报复杂度 + 跑 1–2 个用例。
- **30 分钟 ML System Design**：抽一个场景，按「澄清→数据/特征→召回+精排→评估→A/B→上线监控/回滚」走，面试官中途追问取舍。
- **10 分钟 ML 深广度**：就上面设计里的某个建模选择深挖（为什么这个模型/损失/指标），或抽一道基础题。
- **10 分钟 Behavioral**：一道 STAR（优先「模型上线事故复盘」或「跨团队冲突」）。
- 结束按下方自评表打分，记 1 个最大坑 + 下次改 1 件事。

## A. Coding（DS&A）

- 在 K 个有序链表里合并（堆，[ds-05]）。
- 最长无重复子串 / 最小覆盖子串（滑动窗口，[ds-02]）。
- 岛屿数量 / 腐烂的橘子（BFS-DFS，[ds-03]）。
- 编辑距离 / 最长公共子序列（DP，[ds-04]）。
- 数据流中位数（双堆，[ds-05]）。

## B. ML System Design（重头戏）

- 为信息流产品 Helios Media 设计内容推荐排序系统（[ms-01]）。
- 设计一个搜索结果排序系统（多目标：相关性 + 点击 + 转化）。
- 为电商平台 Northwind 设计「猜你喜欢」召回 + 精排（[ms-06]）。
- 设计一个实时欺诈/异常检测系统（类别极不平衡、低延迟、可解释）。
- 设计特征平台（feature store），保证训练-服务一致（[ms-02]、[ms-03]）。
- 设计模型上线流程：灰度、监控、回滚（[ms-05]）。

## C. ML Breadth/Depth（深广度）

- 模型在训练集 AUC 0.95、线上只有 0.7，怎么排查？（[ms-03]、[mf-01]）
- 类别极度不平衡（1:1000），你怎么建模与评估？（[mf-05]、[mf-03]）
- 这个任务你选树模型还是神经网络，为什么？（[mf-06]）
- 解释偏差-方差，给我一个你实际调过的例子（[mf-01]、[mf-02]）。
- precision 和 recall 怎么权衡，你这个业务该偏哪个？（[mf-03]）

## D. Behavioral

- 讲一次你负责的模型/系统上线出事故，怎么处置和复盘（[bh-03]）。
- 讲一次和 PM/数据/平台团队目标不一致、你怎么对齐（[bh-02]）。
- 讲一次你 own 了职责外的问题（[bh-04]）。
- 讲一次失败的 ML 项目，你学到什么（[bh-01]）。
