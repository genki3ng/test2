# ML Breadth/Depth（基础）— 建模与评估

> 目标：任意一个核心概念能 2 分钟讲清「是什么 + 怎么用 + 坑」，并能就简历项目深挖训练细节。题库见 [../question-bank.md](../question-bank.md) 的「ML 基础」。

## 偏差-方差（必背）

- 泛化误差 ≈ 偏差² + 方差 + 不可约噪声。
- **高偏差 = 欠拟合**（模型太简单，训练误差就高）→ 加复杂度/特征、减正则。
- **高方差 = 过拟合**（对训练集太敏感，训练好验证差）→ 加数据、加正则、简化模型、early stop。
- 诊断工具：学习曲线（误差随样本量），判断该「加数据」还是「加复杂度」。

## 过拟合与正则化

| 手段 | 机制 | 适用 |
|---|---|---|
| **L2（岭）** | 惩罚权重平方，权重整体变小、更平滑 | 通用，防过拟合 |
| **L1（Lasso）** | 惩罚绝对值，产生**稀疏**解 | 特征选择 / 高维稀疏 |
| **Elastic Net** | L1+L2 折中 | 高维 + 相关特征 |
| **Dropout** | 训练随机丢神经元 | 神经网络 |
| **Early stopping** | 验证误差回升即停 | 迭代训练（NN/GBDT） |
| **数据增广 / 加数据** | 扩大有效样本 | 图像/文本等 |
| 树模型：限深 / min_leaf / subsample | 限制复杂度 | GBDT / RF |

## 评估指标（高频）

**分类**
- Precision = TP/(TP+FP)「报出来的有多准」；Recall = TP/(TP+FN)「该抓的抓到多少」；F1 = 调和平均。
- 阈值在 P 与 R 间权衡：欺诈/疾病重 Recall，垃圾拦截重 Precision。
- ROC-AUC：阈值无关、衡量排序能力；**类别极不平衡用 PR-AUC** 更敏感。
- 别只看 accuracy（99% 负样本时全猜负也 99%）；多分类用 macro/micro 平均。

**回归**
- MSE/RMSE：平方放大大误差、对离群点敏感；RMSE 同量纲好解释。
- MAE：对离群点更稳健；Huber 是两者折中。
- R²：解释方差占比（可为负）；MAPE 看相对误差但目标接近 0 时爆炸。

## 类别不平衡

- **数据层**：过采样少数类（SMOTE）、欠采样多数类——只在训练集做。
- **算法层**：class_weight / 加权损失 / focal loss。
- **评估层**：用 PR-AUC、F1、recall@某 precision；阈值按业务调而非默认 0.5。
- 先问「不平衡是否真有害」，优先调评估与阈值，再考虑重采样。

## 树模型 vs 神经网络

| 维度 | GBDT / 树 | 神经网络 |
|---|---|---|
| 数据类型 | 表格/结构化中小规模最强 | 非结构化（图像/文本/序列）、超大数据 |
| 特征工程 | 对缩放不敏感、需手工特征 | 端到端学表征、可迁移学习 |
| 可解释性 | 好（重要性 / SHAP） | 弱（需额外工具） |
| 训练/部署 | 快、轻 | 重、需算力 |

- 集成机制：**Bagging（随机森林）降方差**（并行、各树独立）；**Boosting（GBDT）降偏差**（串行，逐棵拟合残差）。

## Embedding

- 把高维稀疏 ID（词/用户/item）映射到低维稠密向量，相近的东西向量也近。
- 来源：监督端到端（双塔）、自监督（word2vec / 对比学习）、预训练大模型抽取。
- 用法：相似度检索（余弦/点积 + ANN）、做下游特征、冷启动用内容 embedding 兜底。
- 坑：维度选择、归一化、OOV/冷启动、分布漂移需定期重训。

## 损失函数

- 回归：MSE / MAE / Huber；二分类：交叉熵（log loss）；多分类：softmax 交叉熵；排序：pairwise/listwise（BPR、LambdaRank）。
- **分类为什么用交叉熵不用平方误差**：梯度更好、与极大似然/概率一致、不易梯度消失（配 sigmoid）。

## 特征工程

- 缺失值：填充（均值/中位数/特殊值）+ 加缺失标记位。
- 类别：one-hot（低基数）、target encoding（高基数，防泄漏）、embedding。
- 数值：标准化/归一化、分桶、对数变换（长尾）。
- 交叉与时间特征；**防泄漏**：只用预测时点可得的信息、按时间切分、归一化参数只在训练集 fit。
