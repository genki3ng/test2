# 总策略（Strategy）

> 目标：**在 2026-XX-XX 前拿到** 一个匹配度高、级别/地点/团队方向都合适的 offer（自设目标日期，按需填写）。
> 北极星见 [target.md](../profile/target.md)。

## 核心打法

1. **按匹配度筛公司**：先按 匹配度 / 级别 / 地点 / 团队方向 筛 [目标公司](target-companies.md)，再谈级别与薪酬。（若签证/sponsorship 与你相关，作为附加筛选维度，见 [perm-by-company.md](perm-by-company.md)）
2. **自己找 referral**：优先通过内推进入流程（比海投快、回复率高）。
3. **面经驱动准备**：用 **面经网站/社区** 收集目标公司面经 → 反推考点 → 针对性准备，整理进 [company-notes](../prep/company-notes/)。
4. **保密推进**：不在现雇主设备/账号上操作；面试尽量约非工作时间。
5. **集中冲刺**：留出一段相对完整的时间（调休/假期），集中安排 onsite 与谈判。

## 3 个月倒排（到目标日期）

| 阶段 | 时间 | 重点 |
|---|---|---|
| **定位 & 启动** | 第 1 月上 | 补全背景/简历 master；按维度筛目标公司；启动 SQL/Python + 统计练习；铺开 referral 请求 |
| **铺管道** | 第 1 月中下 | 海投+内推到位；recruiter screen；启动 实验/统计 + 产品 sense 准备；行为面 STAR 故事成形 |
| **面试集中** | 第 2 月 | phone / onsite 排期；强化 产品 sense + 实验方法论（Staff/资深关键）；按公司用面经针对性准备 |
| **冲刺 & onsite** | 第 3 月 | 集中 onsite；拿到 offer；启动 comp 调研 |
| **谈判 & 决策** | 目标日期 | offer 对比（按 级别 / comp / 团队 / 地点），谈判，决策；入职时间可谈 |

> 每周在 [journal.md](../log/journal.md) 写一次进展与下周计划。

## 每周节奏（建议）

- SQL/Python：保持手感（量按时间调整）。
- 统计/实验 · 产品 sense · behavioral：各推进 1–2 个主题或故事。
- 管道：新增 referral/投递 N 家；推进所有 in-progress 到下一步。
- 复盘：每场面试后立刻在对应 [公司文件](../pipeline/companies/) 记录。

## 面试排序与节奏（梯次）

> 原则：**先用没那么想去的公司练手攒经验，最想去的放后面**——但**错峰、不要纯串行**。

- **梯次 A（最想去 🟢）**：Northwind / Vertex Cloud —— **稍后启动**，练过 1–2 轮真面试、状态最佳时再上。
- **梯次 B（练手 🟡）**：Helios Media —— **先开**，攒 reps（behavioral / case / SQL 实战手感）。
- **额外练手**：真人模拟面（interviewing.io / 同行 mock），别只拿真公司练手。

**为什么不纯串行（先把练手公司全面完再开梦想公司）：**
1. **offer 会过期**：练手 offer 约 4–6 周到、1–2 周 explode → 等不到梦想公司结果，白拿没杠杆。
2. **时间不够**：到目标日期仅 ~3 个月，Senior/Staff DS 一轮 4–8 周；纯串行会把梦想公司拖到最后才开 = 太晚。
3. **要让 offer 扎堆**：同窗口拿到多个 offer 才好横向比 + 竞争性谈判。

**做法**：本周起开 1–2 家梯次 B 练手；约 2–3 周后（练过、prep 成熟）再开梯次 A；让 onsite/offer 尽量在冲刺期前后扎堆。prep 还在补（SQL/统计）——练手轮正好用 deadline 倒逼完成，别冷启动去面梦想公司。

## 风险 & 对策

- **时间紧（3 个月）**：先聚焦 3–5 家高匹配公司，别摊太广。
- **要求不确定**：尽早在 recruiter 阶段礼貌确认级别、地点与（若相关）签证/sponsorship 口径（话术见 [谈判](../negotiation/README.md)）。
- **边工边面冲突**：用假期/调休；保密。
