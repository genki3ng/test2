# 北极星 与 约束（Target）

> 🧪 **虚构样例（Alex Rivera）——替换成你自己的。** 这是整个求职的「北极星」：任何决策（投哪家、接哪个 offer、怎么谈）都回到这里对照。
> 提示：把首要动机、级别、地区、时间线改成你真实的目标即可；首页页脚的一句话在 `src/site.config.ts` 的 `northStar`。

## 🟢 首要动机

- 用一句话写清你**为什么换工作**、什么最重要（如：更大的 scope / 总包 / 团队方向 / 远程 / 签证 sponsorship）。
- 样例：**升到更大 scope（Senior→Staff 量级）+ 优化总包**，团队要做产品/实验方向。

## 🎯 目标

- 在**保密、稳妥**的前提下寻找机会（在职找）。
- 跳到方向对口、级别匹配的**大/中型公司**。样例点名：**Northwind、Vertex Cloud、Helios Media**（虚构）。

## 🏆 级别

- **主**：Senior（IC5 量级）。**冲刺**：Staff（IC6）。按你的实际情况改。

## 📍 地区

- 样例：**remote 友好 / 美国主要城市均可**。按你的偏好改。
